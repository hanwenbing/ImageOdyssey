# get-image-prompt

这是本项目从中文画廊中选择并适配 GPT Image 2 提示词的固定流程。

## 规则

- 除非用户明确要求外部提示词，否则只使用本仓库的 `data/gallery/gallery*.md` 作为提示词来源。
- 面向用户输出的提示词必须是中文。
- 不生成图片，不调用图像 API；最终产物是供用户粘贴到网页版 ChatGPT 的提示词。
- 不要跳过用户选择步骤。必须先给出 3 个候选，再等待用户选择。
- 对选中提示词只做主体锚点式最小适配，保留候选 prompt 的原始目标场景、风格和结构。
- 上传图片只作为主体参考或参考对象，不是新 prompt 的内容来源。不要把上传图中的背景、服装、人物关系、贴图、自拍质感等自动写进最终提示词。

## 工作流

1. 分析用户上传或引用的图片。
   - 识别主体、场景、视觉风格、构图、颜色、比例、可见文字和关键不确定点。
   - 如果关键细节不清楚，直接说明，不要编造。
2. 搜索 `data/gallery/gallery*.md` 中的合适案例。
   - 优先匹配图片输出类型，例如 UI 截图、信息图、海报、商品视觉、人像、插画或写实摄影。
   - 再比较风格、构图、信息密度、文字需求和画面比例。
3. 给出恰好 3 个候选。
   - 每个候选包含：案例编号、标题、匹配理由、需要调整的点。
   - 候选说明保持简洁，让用户能快速选择。
4. 等待用户选择一个候选。
5. 只改写被选中的提示词，遵守主体锚点规则。
   - 默认保留：候选 prompt 的场景、服装、道具、姿态、表情、构图、光线、镜头、文字内容、画面比例和整体风格。
   - 允许修改：主体锚点、`{argument ... default="..."}` 占位符、明显与上传主体身份冲突的性别或数量称谓、用户明确要求替换的变量。
   - 禁止修改：不要把上传图分析结果改写成全新场景；不要替换候选 prompt 的核心画面设定；不要把上传图里的背景、婴儿、窗边、贴图、自拍质感等无关内容写入最终 prompt。
   - 常用写法：把原 prompt 的主体开头改成“以我上传的图片中的人物为主体”或“以我上传的图片中的主体为参考”，然后继续保留原 prompt 的目标场景。
   - 只有当原 prompt 细节与“以上传图片主体为主体”直接冲突时，才删除或调整该细节。
6. 输出最终结果。
   - 先说明保留了原 prompt 的哪些部分，以及只改了哪些变量。
   - 用 `text` 代码块提供一个最终中文提示词。
   - 不提供英文版本。

## 改写边界示例

反例：如果候选 prompt 是“年轻 goth 女性坐在儿童投币式独角兽游乐设施上”的真实照片，不要因为上传图是室内自拍，就改成“东亚女性和婴儿在卧室窗边自拍，右侧有贴图”。这是把上传图内容重写成新场景，违背主体锚点规则。

正例：应改成“以我上传的图片中的人物为主体，生成一张坦率、真实的照片。人物坐在儿童投币式独角兽游乐设施上，表情 deadpan，直视镜头……”，并继续保留原 prompt 里的 goth 妆容、黑色服装、独角兽游乐设施、商店外墙、NO PARKING FIRE LANE 标牌、蓝色自动售货机、阴天自然光等目标画面设定。

## 搜索建议

优先使用 `rg`：

```bash
rg -n "关键词|主题|风格" data/gallery/gallery*.md
```

如果图片类型较宽泛，先查看 `data/gallery/index.md`，再选择可能匹配的主题分册。
