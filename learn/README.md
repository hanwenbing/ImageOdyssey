# 学习记录

本目录用于存放 React、Tailwind CSS 和 Supabase 的学习笔记、实验代码和相关资料。

## 学习范围

- React
- Tailwind CSS
- Supabase

## 第一阶段：React

起点文档：[Build a React app from Scratch](https://react.dev/learn/build-a-react-app-from-scratch)

这篇 React 官方文档的核心目标是理解从零搭建 React 应用时需要补齐的基础能力：

- 选择构建工具，例如 Vite、Parcel 或 Rsbuild。
- 认识单页应用还需要自己处理的通用问题，例如路由、数据获取、代码分割和性能优化。
- 明确从零搭建适合学习基础，但正式项目通常需要评估框架能力。
